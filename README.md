## Deskripsi

Project ini merupakan implementasi bertahap mini 3D scene menggunakan Node.js, Vite, dan Three.js.

Implementasi saat ini mencakup:

- `Scene` dan background;
- `PerspectiveCamera`;
- `WebGLRenderer`;
- `BoxGeometry`;
- `MeshBasicMaterial`;
- satu cube yang ditambahkan ke scene.

## Cara Menjalankan

```bash
npm install
npm run dev
```
